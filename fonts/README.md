# Roboto incluida en FitoConsulta CR

Tipografía Roboto variable: estilo normal e itálico, pesos 100–900, subconjunto latino que incluye los acentos del español. Toda la interfaz utiliza peso 300 (Roboto Light), incluidos títulos, texto, controles y códigos; se conserva la itálica de los nombres científicos con el mismo peso. La jerarquía se expresa por tamaños, colores y espacios, sin negritas. Los campos y datos de ficha usan 16 px; la información auxiliar no baja de 12 px. Alternativas: Helvetica, Arial y sans-serif.

Los WOFF2 originales se incorporan sin modificar sus bytes mediante URL de datos en `roboto.css`. Esto permite usar la fuente sin conexión incluso al abrir `index.html` por `file://`, sin las restricciones CORS de algunos navegadores para archivos de fuente locales. No hay consultas en tiempo de uso a Google Fonts ni a otro servidor externo.
